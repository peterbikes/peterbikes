## SEA:ME: autonomous mobility project

[SEA:ME](https://seame.space/) (Software Engineering in Automotive and Mobility Ecosystems) is a self-learning, master-level curriculum in software engineering for mobility. Our team built an intelligent mobility system on a JetRacer vehicle, from embedded systems to real-time inference.

**My part: the machine learning model for lane and object detection.**

- U-Net architecture and training pipeline in Python
- Export to ONNX and optimization with TensorRT for real-time inference on a Jetson Nano
- C++ integration to run the model inside the vehicle

🔗 [My ML model repo](https://github.com/peterbikes/SEAME-MachineLearningModel_24-25) · [Full team project: JetPackJoyRide](https://github.com/SEAME-pt/JetPackJoyRide)
